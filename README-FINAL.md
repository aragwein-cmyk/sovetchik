## 🚀 **ЗАПУСК В 2 ШАГА:**

### **Шаг 1: Запустите деплой**
```bash
deploy-now.bat
```

**Что произойдет:**
1. **Очистятся** старые файлы
2. **Соберется** проект для продакшена
3. **Откроется** Vercel в браузере
4. **Нужно будет войти** в аккаунт Vercel

### **Шаг 2: Получите ссылку**
После деплоя Vercel покажет вашу ссылку:
```
https://sovetchik-abc123def456.vercel.app
```
